# Tier List

Ranking system for books. Set `tier` in a book's frontmatter.

| Tier | Meaning | Re-read worthy? | Recommend to others? |
|:----:|---------|:---------------:|:--------------------:|
| **S** | Life-changing, top of the shelf | ✅ | ✅ Always |
| **A** | Excellent, high value | ✅ | ✅ |
| **B** | Good, solid takeaways | ❔ | ✅ For the right audience |
| **C** | Mixed, some value | ❌ | ⚠️ Only with caveats |
| **D** | Not worth the time | ❌ | ❌ |

> [!note] Rules
> - Rank only after finishing the book (`status: read`).
> - Ties are fine. Re-tier freely; the dashboard recalculates.
