# library_books_obsidian

Персональная библиотека книг в [Obsidian](https://obsidian.md): статусы чтения, подробные рецензии, конспекты глав и тир-лист с центральным дашбордом.

## Возможности

- **Статусы книг:** прочитано, читаю, хочу прочитать, брошено.
- **Рецензии:** плюсы и минусы, кому подойдёт, рекомендации, разбивка оценки.
- **Конспекты:** пересказ глав, цитаты, выводы, действия.
- **Тир-лист:** уровни S / A / B / C / D с описанием каждого уровня.
- **Дашборд:** сводка, таблицы по статусам, тир-лист и последние заметки, собранные автоматически.
- **Шаблоны:** для книги, рецензии и конспекта.

## Структура

```
Дашборд.md          Центральная панель
Книги/              По одной заметке на книгу (источник статуса и уровня)
Рецензии/           Подробные рецензии: «<Название> - Рецензия»
Конспекты/          Конспекты глав и цитаты: «<Название> - Конспект»
Шаблоны/            Шаблоны: Книга, Рецензия, Конспект
Мета/               Тир-лист и соглашения
Вложения/           Обложки и изображения
```

## Быстрый старт

1. Установите Obsidian и откройте папку репозитория как хранилище (*Open folder as vault*).
2. Включите встроенный плагин **«Шаблоны»** (Settings → Core plugins → Templates) и укажите папку `Шаблоны`.
3. Установите плагин сообщества **Dataview** (Settings → Community plugins) — без него запросы дашборда не отображаются.
4. Откройте `Дашборд.md`.

## Как пользоваться

1. Создайте заметку из шаблона `Шаблоны/Книга` и заполните поля frontmatter:
   ```yaml
   status: читаю        # прочитано | читаю | хочу-прочитать | брошено
   tier:                # S | A | B | C | D (после прочтения)
   rating: 9            # 1–10
   ```
2. Для рецензии используйте `Шаблоны/Рецензия`, для конспекта — `Шаблоны/Конспект`. Связывайте их с книгой через `book: "[[Название]]"`.
3. Меняйте статус и уровень прямо во frontmatter. Дашборд обновится автоматически.

Подробные соглашения (теги, значения статусов, связи) — в `Мета/Соглашения.md`. Критерии уровней — в `Мета/Тир-лист.md`.

## Требования

- [Obsidian](https://obsidian.md) (настольная или мобильная версия)
- Плагины: «Шаблоны» (встроенный), Dataview (сообщества)
