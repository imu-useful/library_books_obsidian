# 📚 Библиотека — дашборд

> [!info] Как пользоваться
> Книги лежат в папке `Книги/`. Статус и уровень (`status`, `tier`) задаются во frontmatter. Измените их — таблицы ниже обновятся автоматически.
> Требуется плагин сообщества **Dataview**.

## 📊 Сводка

```dataview
TABLE length(rows) AS "Книг"
FROM "Книги"
WHERE type = "book"
GROUP BY status
SORT status ASC
```

## 📖 Читаю сейчас

```dataview
TABLE author AS "Автор", started AS "Начало", file.link AS "Книга"
FROM "Книги"
WHERE status = "читаю"
SORT started DESC
```

## ✅ Прочитано

```dataview
TABLE author AS "Автор", rating AS "Оценка", tier AS "Уровень", finished AS "Окончание", file.link AS "Книга"
FROM "Книги"
WHERE status = "прочитано"
SORT finished DESC
```

## 🔖 Хочу прочитать

```dataview
TABLE author AS "Автор", genre AS "Жанр", file.link AS "Книга"
FROM "Книги"
WHERE status = "хочу-прочитать"
SORT file.name ASC
```

## 🗑️ Брошено

```dataview
TABLE author AS "Автор", file.link AS "Книга"
FROM "Книги"
WHERE status = "брошено"
```

## 🏆 Тир-лист

> [!tip] Уровни
> **S** — шедевр · **A** — отлично · **B** — хорошо · **C** — средне · **D** — не моё. Подробнее: [[Тир-лист]].

```dataview
TABLE WITHOUT ID tier AS "Уровень", file.link AS "Книга", rating AS "Оценка"
FROM "Книги"
WHERE type = "book" AND tier
SORT tier ASC, rating DESC
```

## 📝 Последние рецензии

```dataview
TABLE book AS "Книга", rating AS "Оценка", file.link AS "Рецензия"
FROM "Рецензии"
WHERE type = "review"
SORT file.mtime DESC
LIMIT 5
```

## 🧠 Последние конспекты

```dataview
TABLE book AS "Книга", chapter AS "Глава", date AS "Дата"
FROM "Конспекты"
WHERE type = "reading-note"
SORT date DESC
LIMIT 5
```
