# Соглашения

## Папки
| Папка | Содержимое |
|-------|------------|
| `Книги/` | Одна заметка на книгу. Источник правды для статуса и уровня |
| `Рецензии/` | Подробные рецензии: `<Название> - Рецензия` |
| `Конспекты/` | Пересказы глав и цитаты: `<Название> - Конспект` |
| `Шаблоны/` | Шаблоны заметок (плагин «Шаблоны») |
| `Мета/` | Тир-лист, соглашения |
| `Вложения/` | Обложки и изображения |

## Значения статуса (`status:`)
- `прочитано` · `читаю` · `хочу-прочитать` · `брошено`

## Теги
- `#книга` · `#рецензия` · `#конспект` · `#дашборд` · `#мета`
- Жанры: `genre: [нон-фикшн, продуктивность]` во frontmatter (без `#`)

## Связи
- Книга ↔ рецензия ↔ конспект связаны через `book: "[[Название]]"` во frontmatter.

## Необходимые плагины
- Встроенные: «Шаблоны»
- Сообщества: Dataview (для дашборда)
