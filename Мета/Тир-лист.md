# Тир-лист

Система оценки книг. Уровень задаётся полем `tier` во frontmatter книги.

| Уровень | Значение | Стоит перечитать? | Рекомендовать? |
|:-------:|----------|:-----------------:|:--------------:|
| **S** | Меняет жизнь, лучшее на полке | ✅ | ✅ Всегда |
| **A** | Отлично, большая ценность | ✅ | ✅ |
| **B** | Хорошо, есть полезные идеи | ❔ | ✅ Для подходящей аудитории |
| **C** | Смешанно, есть польза | ❌ | ⚠️ Только с оговорками |
| **D** | Не стоит времени | ❌ | ❌ |

> [!note] Правила
> - Ставьте уровень только после прочтения (`status: прочитано`).
> - Одинаковые уровни допустимы. Меняйте уровни свободно: дашборд пересчитывается.
